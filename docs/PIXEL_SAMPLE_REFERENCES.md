## Interface reference article

[Indieklem: A look at 100+ game interfaces](https://indieklem.substack.com/p/20-a-look-at-100-interface-games) was read for its discussion of synchronized sound/animation, responsive cards, value-specific feedback and interfaces treated as material. Application: the sample has a physical card body, separate coin travel and benefit/curse acknowledgements, rather than one animation for every event. This is an application of the article, not a claim that this sample reproduces a reference game’s timings.
