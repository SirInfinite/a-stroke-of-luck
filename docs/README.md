# a-stroke-of-luck
A top-down 2D golf roguelike where every upgrade comes with a penalty

## MVP

The current prototype is a five-hole 2D golf loop:

- Click and drag from the ball to aim.
- Release left mouse to shoot.
- Sink the ball to advance to the next hole.
- Press `R` to reset the current hole.

For the first roguelike layer, keep the next additions small:

1. Track score across a five-hole run.
2. Offer one upgrade after each hole.
3. Pair every upgrade with a penalty, such as more power but more bounce.
4. Add simple hazard tiles that reset the ball.
5. Randomize hole order once the authored five-hole loop feels good.
